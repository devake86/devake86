# Projekte

Eine Übersicht meiner privaten Entwicklungs-, Lern- und Referenzprojekte.

## Fachinformatiker Lernbegleiter

Deutschsprachige Quiz-Anwendung zur ergänzenden Prüfungsvorbereitung für angehende Fachinformatiker. Die drei Versionen verwenden gemeinsame Fragenkataloge im JSON-Format und speichern den Lernfortschritt lokal.

### [Progressive Web App](https://github.com/devake86/Fachinformatiker-Lernbegleiter-pwa)

**Status:** Früher Prototyp<br>
**Technologien:** Vanilla TypeScript, Vite

Plattformunabhängige Weiterentwicklung der bestehenden Desktop- und Android-Versionen.

[Aktuellen Entwicklungsstand öffnen](https://devake86.github.io/Fachinformatiker-Lernbegleiter-pwa/)

### [Android-Version](https://github.com/devake86/Fachinformatiker-Lernbegleiter-android)

**Status:** RC1<br>
**Technologien:** Java, Android SDK, SQLite, JSON, Gson

Mobile Version mit lokalem Lernstand, Fehlertraining, gespeicherter letzter Auswahl sowie anpassbarer Bedienrichtung und Farbdarstellung.

[APK herunterladen](https://github.com/devake86/Fachinformatiker-Lernbegleiter-android/releases/download/v1.0-rc1/FiLb-android_v1.0-rc1.apk)

### [Desktop-Version](https://github.com/devake86/Fachinformatiker-Lernbegleiter-desktop)

**Status:** RC1<br>
**Technologien:** Java, JavaFX, SQLite, JSON, Gson

Desktopversion für Windows mit lokalem Lernstand, Fehlertraining, gespeicherter letzter Auswahl und anpassbarer Farbdarstellung.

[Windows-Version herunterladen](https://github.com/devake86/Fachinformatiker-Lernbegleiter-desktop/releases/download/v1.0-rc1/FiLb-desktop_v1.0-rc1.zip)
